# Programming for AI – Assignment 3

## How to Run
1. Clone or download this repository.
2. Install the required libraries: `numpy`, `pandas`, and `matplotlib`.
3. Make sure the `data/` folder is in the same directory as the notebook.
4. Open `Assignment3_Programming_for_AI.ipynb` in Jupyter Notebook or JupyterLab.
5. Run all cells from top to bottom.

The generated figures and animation are saved in the `outputs/` folder.

## Challenges
One challenging part was handling and cleaning different types of data correctly. Creating the visualizations and animating the travelling wave while ensuring the outputs were saved properly also required careful debugging.
